<img width="960" height="540" alt="ss5" src="https://github.com/user-attachments/assets/c2e0ba9f-d597-4859-83d4-5960afd94def" /># 🚀 AI ATS Resume Screening System

An AI-powered ATS (Applicant Tracking System) Resume Screening Platform built using Python, NLP, Machine Learning, and Streamlit.

The system automatically analyzes resumes, matches them with job descriptions, calculates ATS scores, extracts skills, identifies missing skills, ranks candidates, and provides recruiter insights through an interactive dashboard.

---

# 📌 Features

✅ AI ATS Resume Screening  
✅ PDF / DOCX / TXT Resume Upload  
✅ NLP-Based Resume Matching  
✅ ATS Score Calculation  
✅ Skill Extraction  
✅ Missing Skills Detection  
✅ Candidate Ranking System

✅ Interactive Charts & Visualizations

# 📝 How It Works

1. Paste Job Description
2. Upload Resume Files
3. AI analyzes resumes using NLP
4. ATS score is calculated
5. Skills are extracted
6. Missing skills are identified
7. Candidates are ranked automatically
8. Dashboard displays recruiter analytics
